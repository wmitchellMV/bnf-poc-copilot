# POC generated for BNF 2.0 using Co-Pilot and Claude Opus 4.6

This POC is a small hierarchical "grid" control built in React (TS) with a small dummy API serving as the backend.

## Debug

To debug, ensure the dotnet project is running first!

```
cd ./GridApi
dotnet build
dotnet run --launch-profile http
```

Once the API runs, start the UI app:
```
cd ./grid-ui
npm install
npm run dev
```
